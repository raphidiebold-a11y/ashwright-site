Server unterstützen

Der Verkauf startet erst, wenn die Abstimmung mit Bohemia Interactive abgeschlossen ist. Hier steht, was geplant ist und was nie verkauft wird.

  • Reservierter PlatzVorschau

    —Preis folgt

    Du sicherst dir einen Platz in Saison 0. Die Whitelist läuft in Wellen, mit der Reservierung bist du in einer davon sicher dabei. Wer startet, startet gemeinsam mit seiner Welle, ein Vorsprung entsteht nicht.

  • SupporterVorschau

    —Preis folgt

    Eine Discord-Rolle, eine Namensplakette beim Chat und ein Eintrag auf der Credits-Wand für alle, die den Server von Anfang an mitgetragen haben.

  • Kleidungs-SkinsVorschau

    —Preis folgt

    Neue Farben und Muster für Jacken, Hosen und Rucksäcke. Gleiche Werte, nur ein anderes Aussehen.

  • Waffen-FinishVorschau

    —Preis folgt

    Anderes Holz, anderer Brünierton, Gravur auf der Handbüchse. Sie schießt exakt gleich.

  • Basen-BannerVorschau

    —Preis folgt

    Fahnen und Schilder für deine Base, mit eigenem Wappen. Reine Dekoration.

  • Eigenes MeisterzeichenVorschau

    —Preis folgt

    Als Meister trägt deine Ware dein Zeichen. Mit diesem Paket gestaltest du, wie es aussieht. Der Wert deiner Ware bleibt, wie er ist.

  • Warteschlangein Klärung

    —Preis folgt

    Bei vollem Server wirst du vor den anderen eingelassen. Das gibt es nur, wenn Bohemia es freigibt, und nur ohne Vorteil im Spiel.

Das kaufst du nie

  • Waffen, Munition, Fahrzeuge
  • Materialien, Barren, Münzen
  • Erfahrung, Skill-Boosts, Rezepte
  • Größere Basen, mehr Lagerplatz
  • Ein früherer Start als deine Welle

Das gilt immer

  • Wer nichts kauft, verpasst im Spiel nichts.
  • Jedes Paket ist eine Sache, die man sieht oder die den Server trägt.
Es gelten die Monetarisierungs-Regeln von Bohemia Interactive für DayZ-Server.

So läuft ein Kauf

So ist es geplant. Es steht noch nichts davon zum Kauf bereit.

  1. 1

    Paket wählen

    Du suchst dir ein Paket aus und zahlst über einen Zahlungsdienstleister. Preise sind inklusive Steuern.

  2. 2

    Steam64-ID angeben

    Die brauchen wir, damit das Paket an deinem Konto hängt. Dieselbe ID wie bei der Whitelist.

  3. 3

    Automatisch freigeschaltet

    Rolle im Discord und Eintrag auf dem Server, ohne dass du auf uns warten musst.

Du willst Bescheid wissen, sobald es losgeht? Im Discord gibt es einen Ping für den Shop-Start.
